# ScreenMatch 🎬

Aplicação desenvolvida em Java com Spring Boot para consultar informações de séries utilizando a API da OMDb.

## 📌 Sobre o projeto

O ScreenMatch permite pesquisar séries pelo nome, consultar suas temporadas e episódios e trabalhar com os dados retornados pela API.

O projeto foi desenvolvido durante meus estudos de Java e Spring Boot, com foco em orientação a objetos, consumo de APIs e manipulação de dados.

## ⚙️ Funcionalidades

- Busca de séries pelo nome.
- Consulta das temporadas disponíveis.
- Listagem de episódios.
- Conversão dos dados JSON em objetos Java.
- Manipulação e filtragem de episódios.
- Consulta de episódios a partir de um ano informado.

## 🛠️ Tecnologias utilizadas

- Java 21
- Spring Boot
- Maven
- API OMDb
- Git e GitHub
- Programação Orientada a Objetos (POO)
- Streams e Collections do Java

## ▶️ Como executar o projeto

1. Instale o Java 21 ou uma versão compatível com o projeto.
2. Clone este repositório.
3. Configure uma chave válida da API OMDb.
4. Configure a variável de ambiente `OMDB_API_KEY` na configuração de execução da aplicação.
5. Execute a classe `ScreenmatchApplication`.

### Configuração da API

A aplicação utiliza a variável de ambiente `OMDB_API_KEY` para acessar a API OMDb.

Não coloque sua chave diretamente no código nem a publique no repositório.
